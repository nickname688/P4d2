# 四一致超图中禁用 P₃ 且最大度为 2 的极大边数问题

## 问题描述

考虑一个 **4-一致超图**（即每条超边恰好包含 4 个顶点），满足以下两个条件：

1. 具有分量最大的点度为2；
2. **图中不包含 P₃** —— 这里 P₃ 指一条由三条超边构成的“长度为 3 的线性路”。

在满足上述约束的前提下，**求边数达到极大值时的可能构型数量**，进一步研究定点数可以达到的上界。


The Maximum Number of Edges in a 4-Uniform Hypergraph Forbidden from Containing \( P_3 \) and with Maximum Degree 2
Problem Statement

Consider a 4-uniform hypergraph (i.e., each hyperedge contains exactly 4 vertices) satisfying the following two conditions:

1. The maximum vertex degree is 2;
2. The hypergraph contains no \( P_3 \)—here, \( P_3 \) denotes a "linear path of length 3," consisting of three hyperedges.

Under these constraints, determine the number of distinct extremal configurations that achieve the maximum possible number of edges, and further investigate the upper bound on the number of vertices attainable in such hypergraphs.
